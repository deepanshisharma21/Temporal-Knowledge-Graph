# Temporal Knowledge Graph over Meeting Transcripts
Turns meeting transcripts into a searchable knowledge graph with time tracking.
## Demo
Run: pip install networkx, then python demo.py

This prototype uses sample transcripts, keyword-based extraction and an in-memory graph (NetworkX). It shows candidate journeys across rounds, status changes with time windows, and cross-department concerns.
